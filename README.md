# Indeed UI Clone - React & Tailwind CSS

A high-fidelity, responsive landing page clone of an Indeed home page(Found in Figma Community). This project focuses on **Pixel Perfect** implementation, modular component architecture, and seamless mobile adaptation.

## 🚀 Live Demo
[**Click here to view the live project**](https://indeed-landing-page.vercel.app/)

## 🛠️ Tech Stack
- **Framework:** React.js
- **Styling:** Tailwind CSS (Custom configurations)
- **Deployment:** Vercel

## 🏗️ Architecture & Organization
The project follows a highly organized and scalable folder structure to ensure code reusability and maintainability:

- **`src/components/ui`**: Atomic components like custom Buttons, Inputs, and interactive UI elements.
- **`src/components/sections`**: Major page sections (Hero, Job Cards, Bento Grid Presenter...).
- **`src/components/layouts`**: Global structural components such as the Navbar and Footer.

## ✨ Key Features
- **Design Adaptation:** Replicated the Desktop interface from a Figma template with high precision.
- **Custom Mobile UX:** Since the desktop template was the primary source, I designed and implemented a custom mobile layout to ensure a smooth user experience.
- **Interactive Elements:** Fully implemented hover states, active transitions for buttons, and responsive input fields.
- **Clean Code:** Focused on DRY (Don't Repeat Yourself) principles by using modular components.

## 📖 What I Learned
- Mastering **Tailwind CSS** for complex layouts without leaving the HTML.
- How to structure a React project professionally using a component-based hierarchy.
- Solving design challenges when adapting Desktop-first templates to Mobile screens.
